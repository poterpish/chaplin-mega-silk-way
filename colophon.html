About This Project

This website was created by Alua Kurmanbay as part of the Web Technologies course. The project is based on Chaplin Mega Silk Way, a real cinema located in Astana. The website contains four pages: Home, Movies, Booking and Colophon.

The project was written using HTML. Each page uses semantic elements to organize the content and make the document structure clear. No CSS or JavaScript is used in this assignment.

The main goal was to create a structured multi-page website using meaningful HTML elements instead of focusing on visual design. The pages are connected with relative links through the navigation menu.

HTML Structure

For example, the main content of every page is placed inside the <main> element.

A basic section of the project can be represented like this: 

<section>
    <h2>Section Title</h2>
    <p>Section content</p>
</section>

This structure keeps related information together and gives each content block a clear heading.

Development Process

The website files were created and edited locally on a computer. During development, changes were saved in a Git repository. After making a meaningful change, the updated files could be prepared for a commit.

For example, pressing Ctrl + S saves the current file in the editor. A Git command can then be entered in the terminal. 

git status
git add .
git commit -m "Update website"

After a successful commit, Git may display output such as nothing to commit, working tree clean.

Project Notes

The Movies page presents cinema information in a table, while the Booking page demonstrates an HTML form. The Home page introduces the cinema and provides its location. This Colophon page documents how the website was created.

The booking form is currently a demonstration only. It does not connect to a server, process payments or create real cinema reservations. Real tickets should be purchased through the official Chaplin Cinemas service.
